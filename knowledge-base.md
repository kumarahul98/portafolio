## Key Projects

### Health Tech — Principal Solutions Architect
Health Tech App for doctors to manage patients. Architected and implemented a scalable ETL pipeline to process FHIR healthcare data, perform patient metric calculations, enrich datasets with additional derived metrics, and synchronize processed data with the application layer. Built integrations with multiple EMR systems to ingest clinical data over FHIR APIs. Designed the solution using AWS and Databricks, leveraging EventBridge, Step Functions, S3, and Databricks Serverless.

### Counterfeit Detection — Principal Solutions Architect
Tool to stop counterfeit products by detecting unauthorized listings using images. Led the development of the Counterfeit Detection platform, building a scalable batch-processing system on AWS. Implemented job orchestration for AWS Bedrock batch inference using Lambda, EventBridge, DynamoDB, and S3.

### Health Tech (Data Processing) — Principal Solutions Architect
Architected and implemented the data processing pipelines and migrated stored procedures from PostgreSQL to Databricks, facilitating the transition of OLAP workloads away from the OLTP database.

### Global Cruise Operator — Principal Solutions Architect
Led the development of a Replication Engine POC for a cruise company to synchronize data between shore and ship environments. Designed an offline-tolerant replication architecture using open-source technologies (Debezium, Kafka, Python services on Kubernetes/EKS).

### Warehouse Management — Senior Data Engineer
Architected and built an analytics pipeline for various BI use cases. Took data from various sources (CSV files, NFS, DDB stream, etc.) and stored it in S3. Used AWS Glue jobs to transform data and move it to the lakehouse. Created BI dashboards using AWS QuickSight.

### DB Migration — Data Engineer
Migrated close to 32 million records from CouchBase to OpenSearch with minimal downtime. Built a private API for integration with the rest of the application.

### OnLeave — Tech Lead
Leave Management application built on top of Slack. Led the team, built the whole backend on AWS serverless services (DynamoDB, Lambda Function, API Gateway). Implemented event-driven architecture using SQS and EventBridge. Written in TypeScript, frontend built with React and AWS Amplify.

### Medical Portal — Backend Engineer
Search Application to query records with millisecond latency. Architected an efficient and scalable API using Lambda and OpenSearch.
